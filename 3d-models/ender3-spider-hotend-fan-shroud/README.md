# Ender 3 Spider Hotend Fan Shroud

Printable fan shroud extracted from the Ender 3 Spider toolhead assembly. This folder contains only the final printable shroud body.

## Files

- `spider-hotend-fan-shroud.stl` — print-ready mesh
- `spider-hotend-fan-shroud.3mf` — slicer-ready model file
- `model-files.zip` — convenient download containing both formats
- `installed-toolhead-view.png` — reference view of the shroud in the toolhead assembly

## Compatibility

- Ender 3-style X carriage using the Spider hotend toolhead configuration from this project
- 50 × 15 mm radial blower and corresponding source-assembly hardware

Verify all dimensions, fastener locations, fan orientation, wire routing, probe clearance, and full carriage travel before installation.

## Print guidance

Use PETG, ABS, ASA, or another heat-tolerant material. PLA is not recommended for sustained heat near a hotend. A practical starting point is 0.20 mm layers, 3–4 perimeters, and at least 20% infill.

## Safety and license

This is a heat-adjacent printer component. Inspect airflow, wiring clearance, temperature suitability, and fit before use. Use at your own risk.
